# Changelog

Appendix C of the [Organizational Sovereignty Standard](STANDARD.md). Each published version is a signed git tag on this repository.

| Date | Version | Change |
|---|---|---|
| 2026-09-27 | v0.1 draft | First normative restatement of the source specifications; marks `[runs]`/`[planned]` set from the state of the reference implementations on this date. Named Organizational Sovereignty Standard (OrgSov); mark "Sovereign Organization" defined. |
| 2026-10-10 | v0.2 draft | §2b Invariants added as a section of its own, seven invariants named by word (Cause; Isolated, Granted, Evidenced; Truth, Trust, Traceable). Part A rewritten as access sovereignty with three invariants (isolated · granted · evidenced); terms node, path, access layer added; zone redefined as a scope that grants no path; declared scope (A6) added; effects moved to Part B; knowledge regrouped as Part C under truth · trust · traceable; board overview (unnumbered) and §1 placement among ISO 42001, ISO 27001, NIST AI RMF and the Three Lines Model added; `[open]` mark introduced for A2.5 and A3.3. On publication: text licensed CC BY 4.0 (conformance code Apache-2.0); changelog moved out of the standard into this file; §10 anchors linked to baotrinh.com; §11 points to public issues as the co-audit channel; §1.3 NIST AI RMF mapping corrected (GOVERN 1.4 → GOVERN 2.1, MAP 3.3 → MAP 3.5, MANAGE 2.3 restated as response to newly identified risks). |
| 2026-10-11 | v0.2 draft | Scope widened from AI agents to every actor — people, AI agents, vendors, attackers holding a device: subtitle in STANDARD.md and README now reads "Checkable requirements for organizations whose people and AI agents reach systems and produce knowledge."; Overview for the board replaced with the approved text; README opening rewritten to the same scope, ending "AI agents make this urgent; they are the reason for the standard, not its boundary." Full names "Access sovereignty" and "Knowledge sovereignty" used in the Part A and Part C headings, the README Parts table and the conformance table. §1.1 and the README Parts table: effects are what an actor does, not what an agent does. §1.2 (control set for every actor; ISO 27001 named alongside ISO 42001 and NIST AI RMF), §1.3 (Part A covers every connection through the access layer, whoever the actor) and §9 (any action, by a person or an AI agent) aligned to the same scope. |
| 2026-10-11 | v0.3 draft | Access invariants renamed and restated as properties: Isolated → *Isolated zone* (no standing path into a zone; every path opened by a grant and closing on its own; a compromised node reaches no further than its current grants), Granted → *Human-granted* (adds: an AI agent never grants), Evidenced → *Tamper-proof evidence* (nothing edited or deleted, by anyone, the operator included). Knowledge invariants keep their names and gain a lead phrase: Truth — reasoned by a person or an AI agent; Trust — signed by a human only; Traceable — a living system, claims promoted and demoted by named moves. Overview, Part A definition, A1–A5 headings and §10 use the new names; "Three words" becomes "Three properties". Conformance claims read v0.3. No clause changes requirement. |
